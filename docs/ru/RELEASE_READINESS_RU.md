# Проверка готовности XCEasy Examples

Дата: 2026-09-07. Проверен код commit `c2fc937` с XCEasy 0.1.2.
Область проверки — репозиторий examples, не выпуск
фреймворка XCEasy или Runner.

## Подготовленные изменения

- Preview рядом с шестью экранами каждого приложения и UIKit-баннером.
- Debug-only адаптеры и состояния ошибки, загрузки, раскрытия и пустой выдачи.
- `scripts/generate.sh` находит полный Xcode без системного переключения.
- Тестовые скрипты по умолчанию используют пакет XCEasy 0.1.2 с релизного тега.
- README на двух языках описывают Canvas, генерацию и доверие к макросу.

## Подтверждённые проверки

- `scripts/check-ci.sh`: SwiftLint, генерация и Debug-сборки обеих схем прошли.
- Release-сборки обеих схем для generic iOS Simulator прошли.
- `git diff --check` и проверка синтаксиса shell-скриптов прошли.
- Прямых `find(...)` в файлах сценариев UI-тестов не обнаружено.

- После разрешения `XCEasyMacroPlugin` полный `./scripts/check-all.sh` с релизным
  пакетом завершился с кодом 0: обе схемы, 56 результатов Allure — 46 passed
  и 10 намеренных failed из failure showcase. Неожиданных падений нет.
- Hosted CI для `c2fc937` прошёл: установка инструментов, доступ к приватной
  зависимости, генерация и сборки UIKit/SwiftUI.

CI проверенного кода: https://github.com/qa-point/xceasy-examples/actions/runs/34117390172

## Ограничения проверки

- Preview компилируются; автоматизированная проверка JIT-рендера Canvas после
  переноса в исходные файлы не выполнялась. Сборка и UI-тесты её не заменяют.
- Для приватного пакета требуется доступ к репозиторию XCEasy; в CI используется
  существующий `XC_EASY_INTEGRATION_TOKEN`.
- На новой машине перед UI-тестами необходимо разрешить `XCEasyMacroPlugin`
  в Xcode. Проверка доверия не отключалась.

Релизный кандидат 0.1.0 прошёл сборки и полный демонстрационный UI-прогон.
