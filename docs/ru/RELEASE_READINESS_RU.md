# Проверка готовности XCEasy Examples

Дата: 2026-09-07. Базовый commit: `549ad4a`; проверены локальные изменения Preview
и скриптов подготовки. Область проверки — репозиторий examples, не выпуск
фреймворка XCEasy или Runner.

## Подготовленные изменения

- Preview рядом с шестью экранами каждого приложения и UIKit-баннером.
- Debug-only адаптеры и состояния ошибки, загрузки, раскрытия и пустой выдачи.
- `scripts/generate.sh` находит полный Xcode без системного переключения.
- Тестовые скрипты по умолчанию используют пакет XCEasy 0.1.2 с релизного тега.
- README на двух языках описывают Canvas, генерацию и доверие к макросу.

## Подтверждённые проверки

- `scripts/check-ci.sh`: SwiftLint, генерация и Debug-сборки обеих схем прошли.
- Release-сборки обеих схем для generic iOS Simulator прошли.
- `git diff --check` и проверка синтаксиса shell-скриптов прошли.
- Прямых `find(...)` в файлах сценариев UI-тестов не обнаружено.

## Незакрытые условия выпуска

1. Полный `TUIST_XCEASY_USE_LOCAL_PACKAGE=0 ./scripts/check-all.sh` остановился
   на компиляции: Xcode требует разрешить `XCEasyMacroPlugin` из пакета XCEasy.
   Тесты не запускались. После разрешения повторить прогон; ожидаемый итог
   демонстрационного отчёта — 46 passed и 10 намеренных failed.
2. Требуется зелёный hosted CI для итогового commit examples. Ранее наблюдавшаяся
   блокировка аккаунта не повторилась при свежих проверках XCEasy и Runner.
3. После переноса Preview повторно проверить Canvas из исходных файлов
   SwiftUI-экрана, UIKit-контроллера и UIKit-баннера. Сборка не подтверждает
   успешный JIT-рендер. После генерации при необходимости переоткрыть workspace.

Последний CI: https://github.com/qa-point/xceasy-examples/actions/runs/33427501929

Публикация release и создание версии не выполнены. До закрытия условий выше
состояние — подготовленный локальный кандидат, не подтверждённый релиз.
