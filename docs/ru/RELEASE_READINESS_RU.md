# Проверка готовности XCEasy Examples 0.1.1

Русский · [English](../en/RELEASE_READINESS_EN.md)

Дата: 2026-09-09. Набор версий: Examples 0.1.1, XCEasy 0.1.3, Runner 0.1.3.

## Подтверждённые проверки

- Полный `TUIST_XCEASY_USE_LOCAL_PACKAGE=1 ./scripts/check-all.sh` с исходниками
  кандидата XCEasy 0.1.3 прошёл для обеих схем: 56 результатов Allure,
  46 passed и 10 намеренных failed из failure showcase. Неожиданных падений нет.
- После публикации XCEasy `./scripts/check-ci.sh` прошёл без локальной подмены:
  SwiftLint, генерация и Debug-сборки UIKitExample и SwiftUIExample разрешили
  публичный пакет XCEasy с точного тега 0.1.3.
- Публичная зависимость не требует персонального integration token.
- Отдельная приёмка установленного Runner через PATH и на двух симуляторах
  относится к его релизному процессу. Версия 0.1.3 исправляет обнаруженную
  при проверке установки ошибку поиска runtime при запуске короткого имени.

## Границы проверки

- Намеренные падения демонстрируют диагностические артефакты и не скрываются.
- Автоматизированная проверка JIT-рендера Canvas не выполнялась.
- На новой машине может потребоваться разрешить XCEasyMacroPlugin в Xcode.
- Генерируемые workspace, отчёты и локальные файлы машины не входят в релиз.
